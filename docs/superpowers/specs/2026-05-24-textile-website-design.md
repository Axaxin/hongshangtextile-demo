# 鸿尚纺织官网设计文档

**公司**：佛山市鸿尚纺织有限公司（Foshan Hongshang Textile Co., Ltd.)  
**日期**：2026-05-24  
**状态**：已确认，待实现

---

## 1. 项目背景

鸿尚纺织是1688认证超级工厂，位于中国针织名镇广东佛山张槎，主营针织面料的研发、设计、生产和销售。现有素材包括：工厂实景图、产品 Banner 图、资质证书图、工厂数据指标（4600㎡、5000万+年交易、50+设备）。

---

## 2. 目标与受众

**受众**：国内采购商（服装品牌、中间商）+ 海外采购商（外贸客户），两者兼顾，网站提供中英双语。

**首要目标**：
1. 产品展示——让采购商浏览面料系列、了解规格
2. 询盘转化——引导访客留下联系方式，获取报价

---

## 3. 技术架构

**方案**：Cloudflare Pages（静态托管）+ Cloudflare Workers（表单处理）+ Cloudflare KV（数据存储）+ CF Email Routing（邮件通知）

**前端**：纯静态 HTML + CSS + JS，无前端框架，直接部署到 CF Pages，Git 推送自动触发部署。

**多语言**：中文默认路径（`/`），英文路径（`/en/`），两套独立 HTML 文件，共用同一套 CSS 和图片资源，导航栏 ZH/EN 链接切换，纯路径跳转无 JS 动态渲染。

**目录结构**：

```
/
├── index.html
├── products.html
├── about.html
├── contact.html
├── en/
│   ├── index.html
│   ├── products.html
│   ├── about.html
│   └── contact.html
├── assets/
│   ├── css/style.css
│   └── js/main.js
├── shop-pic/           # 现有图片素材（直接引用）
└── worker/
    └── inquiry.js      # CF Worker：处理询盘表单
```

## 5. 站点结构与页面设计

### 5.1 首页（`/index.html`）

区块从上到下：

1. **导航栏**：Logo（鸿尚纺织 / HONGSHANG）· 产品系列 · 关于我们 · 联系我们 · ZH/EN 切换。固定顶部，滚动后加半透明深色背景。
2. **Hero 区**：全宽背景图（使用现有 `Homepage Image` 素材），叠加大标题"专业针织面料 / 源头工厂直供"，副标题，橙色"立即询盘"CTA 按钮。
3. **数字指标条**：4600㎡工厂面积 · 5000万+年交易额 · 50+加工设备 · 20年行业经验。深色卡片横排，数字用橙色强调。
4. **产品系列网格**：8个面料分类（棉麻、色织、提花、罗纹、全棉、毛纺、经编、混纺），每格一张产品图 + 系列名，点击跳转 `/products.html` 并定位到对应分类。
5. **为什么选择我们**：6个优势图标卡——超级工厂 · 跨境经验丰富 · 加工定制 · 大量现货 · 研发团队 · 一站式服务。
6. **资质证书横条**：展示现有证书图片，传递信任感。
7. **询盘 CTA 区块**：大字召唤文案 + 跳转联系页的橙色按钮。
8. **页脚**：公司名 · 地址（佛山市张槎）· 联系邮箱 · 快速链接 · 版权信息。

### 5.2 产品系列页（`/products.html`）

- 顶部分类 Tab 导航（棉麻 / 色织 / 提花 / 罗纹 / 全棉 / 毛纺 / 经编 / 混纺），点击过滤对应产品卡片。
- 产品卡片网格：产品图片 + 产品编号（如 9282#）+ 规格简述（幅宽/克重）+ "询盘"按钮。
- 点击卡片弹出模态详情面板：展示大图、完整规格参数、询盘按钮，无独立产品详情页。

### 5.3 关于我们页（`/about.html`）

- 公司介绍段落（基于现有素材文案）
- 工厂实景图组（4张车间图横排或网格）
- 数字指标重复展示
- 资质证书（`COMPANY CERTIFICATE` 区块，使用现有证书 Banner 图）

### 5.4 联系 & 询盘页（`/contact.html`）

**询盘表单字段**：
- 姓名（必填）
- 公司名称
- 邮箱（必填）
- WhatsApp / 电话
- 感兴趣的产品系列（下拉多选）
- 备注 / 具体需求（文本域）
- 提交按钮

**提交后**：前端展示"感谢，我们会在1-2个工作日内联系您"提示信息，保留在当前页面。

**其他联系方式**：邮箱 · WhatsApp · 公司地址，与表单并排展示。

> **实现前需确认**：实际联系邮箱、WhatsApp 号码、公司完整地址（需填入 HTML 和 Worker 配置）。

## 6. 数据流：询盘表单

```
用户填写并提交表单（POST /api/inquiry）
  → CF Worker（inquiry.js）接收请求
  → 校验必填字段（姓名、邮箱）
  → 写入 CF KV（key: inquiry:{timestamp-uuid}，value: JSON 表单数据）
  → 通过 CF Email Routing 发送通知邮件到指定邮箱
  → 返回 200 JSON {success: true}
  → 前端展示感谢提示

若 KV 写入失败：
  → Worker 仍尝试发送邮件，确保不漏询盘
  → 记录错误日志到 Worker console

若表单校验失败：
  → 返回 400，前端高亮错误字段并保留已填内容
```
